# Evidence-Grounded Document Intelligence: Grounded RAG Pipeline

## Pipeline Execution Flow
```
Document Upload -> Layout Parsing -> Page-Preserving Chunking -> Vector & Keyword Indexing
                                                                           |
User Query ------> Hybrid Retrieval (Dense Qdrant + Sparse BM25) <---------+
                               |
                   Reciprocal Rank Fusion (RRF)
                               |
                   Cross-Encoder Reranker
                               |
               Top-K Context Construction & Grounding
                               |
            Local LLM (Qwen2.5) with Strict Citations
                               |
        Citation Validation & Abstention Verification Gate
```

## Hybrid Search & Fusion Formula
Dense scores from Qdrant and sparse scores from BM25 are fused using Reciprocal Rank Fusion:

$$RRF(d) = \sum_{m \in \{dense, sparse\}} \frac{w_m}{k + \text{rank}_m(d)}$$

Where default $k=60$, $w_{dense}=0.6$, and $w_{sparse}=0.4$.

## Citation Validation and Abstention Gate
Every statement generated by the LLM must cite an evidence passage `[Citation: N]`.
The system validates:
1. Is passage $N$ present in the retrieved candidates?
2. Does passage $N$ substantiate the factual tokens asserted?
3. If no evidence candidates exceed relevance confidence or the query is unanswerable, the engine returns an explicit `ABSTAIN` code.
